# macOS 桌面版

支持 macOS 26 及以上的 Apple Silicon（ARM64）Mac。应用内置 Node、slang 索引器及 FST 读取器，无需另装运行环境。Web/CLI 仍按项目 README 中的方式启动。

## 下载与安装

1. 在 GitHub Actions 中运行或选择通过的 **Desktop macOS ARM64** 工作流，下载 `RTL-Browser-macOS-arm64` 产物并解压。此工作流不会自动发布 Release。
2. 使用附带的 `SHA256SUMS` 校验 DMG/ZIP：在下载目录运行 `shasum -a 256 -c SHA256SUMS`。
3. 打开 DMG，将 **RTL Browser.app** 拖到 Applications；也可以解压 ZIP 后移动应用。不要直接在只读磁盘映像内使用。
4. 当前包仅有 ad-hoc 签名，没有 Apple Developer ID 和公证。首次打开可能被 Gatekeeper 阻止。确认来源与校验值后，在“系统设置 → 隐私与安全性”中使用“仍要打开”。受组织策略管理的 Mac 可能无法允许此类应用；本项目不提供关闭系统安全检查的命令。

安装包只有在工作流全部通过后才上传。仓库中的 CI 配置不等于已经完成实际的安装验收。

## 使用

- 启动应用，选择一个可写的工程目录，设置 filelist 和 top，编译后浏览源码、层次、端口和诊断。
- 打开波形面板，通过原生文件选择窗口手动选择 `.fst`。程序检查波形与 RTL 顶层是否匹配；不匹配会显示错误。支持的波形格式仅为 FST。
- 波形缩放、平移、信号分组、颜色、活动/固定游标和快捷键与 Web 版一致。Ctrl+W 添加信号，Ctrl+F 定位搜索，H 切换信号层次名称；Ctrl+滚轮缩放，Shift+滚轮平移，拖选时间范围放大。
- 使用“保存布局”保存当前波形布局；下次手动打开同一波形后恢复。布局和快照仍可导出、导入，导出时选择文件保存位置。
- “文件 → 最近工程”重新打开工程。关闭窗口后可以点击 Dock 图标恢复；Cmd+Q 会停止后台服务和工作进程。
- 后台异常退出会显示重试提示。可以用“文件 → 重启后台服务”重启；已完成的索引和已保存的布局保留，未完成的编译需要重试。

## 保存位置与更新

工程配置、索引、编译报告和保存的布局放在工程的 `.rtlb/desktop/`。桌面版不会复用或清除 Web 的 `.rtlb/sessions/`。工程目录必须可写，原始 RTL 不会被修改。复制或移动整个工程后，含有旧绝对路径的配置可能需要重新创建；遇到状态损坏时，程序保留原文件并报告错误。

主题、窗口尺寸和最近工程记录放在应用的用户数据目录 `~/Library/Application Support/RTL Browser/`。这些记录只在本机使用，不打入分发包。

更新时退出应用，下载新版并替换 Applications 中的应用。当前没有自动更新。卸载应用不会删除工程里的 `.rtlb/desktop`；删除该目录会丢失桌面索引与布局，请先备份需要的状态。

沙箱开发和安装验收见 [桌面开发说明](desktop-development.md)。

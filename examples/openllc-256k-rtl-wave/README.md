# OpenLLC 波形使用指南

## 打开波形

在 RTL Browser 仓库根目录启动服务：

```sh
./tools/macos.sh serve --workspace "$PWD/examples/openllc-256k-rtl-wave"
```

打开终端显示的地址，按以下步骤操作：

1. 点击“打开目录”，选择 `examples/openllc-256k-rtl-wave`。
2. 使用 Filelist 输入方式，填写 `design.f`；Top 为 `TOP`，启用单编译单元，添加宏 `VERILATOR`（值留空）。
3. 点击“编译并建立索引”，等待完成。已有可用快照时可直接打开快照。
4. 进入底部 **Waveform** 标签，点击“浏览…”选择 `wave/llc-256k.fst`，再打开波形。
5. 搜索下面的信号，点击结果添加到波形列表：

| 信号 | 用途 |
|---|---|
| `TOP.TestTop.l3.clock` | 观察时钟、练习缩放和游标操作 |
| `TOP.TestTop.l3.reset` | 观察复位 |
| `TOP.TestTop.l3.io_rn_0_tx_req_flit` | 查看 162 位总线 |

波形需要手动打开，刷新页面后也不会自动加载。如果没有上述 FST 文件，请选择自己保存的、与当前 RTL 匹配的仿真波形。

曲线区域太小时，向上拖动底部面板的顶边。展开“分组、颜色与游标设置”可查看更多操作。

## 缩放与浏览时间

| 操作 | 效果 |
|---|---|
| “放大”/“缩小”，或 `+` / `-` | 缩小/扩大显示的时间范围；`=` 也可放大 |
| 曲线上 `Ctrl+滚轮` | 以鼠标位置为中心缩放，向上放大、向下缩小 |
| 曲线上 `Shift+滚轮` | 按滚动量连续浏览前后波形，时间窗口宽度不变 |
| 左键横向拖选曲线区域后松开 | 将选中的时间区间铺满窗口 |
| “全览”或 `Home` | 显示整个波形文件的时间范围 |
| 工具栏 `←` / `→` | 向前/向后平移时间窗口 |

拖选可以从左向右，也可以从右向左；拖动至少 5 像素后视为选区操作，不改变游标位置。时间单位见工具栏中的 `1 tick` 说明。

## 活动游标与固定游标

波形有两个活动游标：**左键单击控制主游标，右键单击控制副游标**。未恢复已有布局时，两者初始位于当前窗口中间。面板显示各自的绝对位置，以及 `Δ(副−主)`；副游标在主游标左侧时，差值为负。

启用“边沿吸附”后，在跳变附近点击即可对齐边沿。信号名称下方显示主游标所在时刻的值。

需要标记重要时刻时：

1. 将主游标移到目标位置。
2. 点击“添加固定游标”，输入名称、选择颜色并保存。
3. 重复以上操作可添加多个固定游标。

固定游标不会随活动游标移动。点击波形顶部的名称可改名、改色；展开“固定游标”列表可定位或删除标记，并查看它与主游标的时间差。

固定游标名称与时间刻度始终停留在信号区域顶部，不随信号列表向下滚走。名称统一显示在同一行；同一时刻的名称并排显示，悬停可查看完整名称和时间。

## 查找跳变

先选中一个信号，再使用以下操作：

| 操作 | 效果 |
|---|---|
| `N` 或 `→` | 主游标移到下一跳变 |
| `Shift+N` 或 `←` | 主游标移到上一跳变 |
| `Alt+←` / `Alt+→` | 副游标移到上一/下一跳变 |
| “上一/下一上升沿”“上一/下一下降沿” | 查找单比特信号的指定边沿 |

跳变位于当前窗口之外时，视图会自动移过去。总线支持普通跳变查找。

## 名称、分组与颜色

信号默认显示短名。点击“显示层次 (H)”或按 `H` 切换完整层次路径；悬停名称也可查看全路径。

| 操作 | 用法 |
|---|---|
| 多选 | `Ctrl+点击`，macOS 用 `Cmd+点击`；`Shift+点击` 连续选择 |
| 创建分组 | 选中信号或已有分组，按 `G`，输入名称 |
| 折叠/展开 | 点击组名前的箭头 |
| 重命名分组 | 选中组后按 `F2`，或点击“重命名” |
| 排序/归组 | 拖动信号名称到目标行前，或拖到组的“拖入此组”区域 |
| 移出分组 | 拖到列表底部“移出分组并放到列表末尾”的区域 |
| 上移/下移 | 点击按钮，或按 `Alt+↑` / `Alt+↓` |
| 改色 | 选中信号或分组后按 `1–8`，或使用色板、信号名称上的右键菜单 |
| 移除 | 选中后按 `Delete`，或点击对应行的删除按钮 |

“解散”分组会保留成员；删除分组会同时移除其成员。对组改色会应用到全部组内信号。

## 与源码联动

- 在源码信号上悬停或聚焦，按 **Ctrl+W** 添加波形，也可用源码右键菜单“添加到波形”。macOS 同样使用 Control；若浏览器占用该快捷键，请使用右键菜单。
- 双击波形曲线或信号名称，跳到对应 RTL 声明；可继续使用源码右键菜单的 Driver / Load 追踪。
- **Ctrl+F** 聚焦当前操作区域的搜索栏，macOS 也支持 Cmd+F。

除搜索快捷键外，波形快捷键应在波形区域获得焦点、且未编辑输入框时使用。曲线上的右键用于副游标；改色等菜单从信号名称处打开。

## 保存与恢复布局

点击“保存布局”或在波形区按 **Ctrl/Cmd+S**，保存信号列表、分组、颜色、时间窗口和游标。临时调整后，可点击“恢复布局”回到保存的状态。

刷新页面后，先打开同一 RTL 工程，再手动打开同一个 FST，保存的布局会自动恢复。换浏览器、端口或机器时，使用“导出布局”保存 JSON；在目标环境打开匹配的 FST 后，再“导入布局”。

## 常见问题

- **顶层不匹配**：本示例 Top 应为 `TOP`，不是 `OpenLLC`；确认选择了配套的 FST。
- **找不到信号**：确认实例路径正确且仿真已记录该信号。部分内部线网没有保留在 FST 中，界面会尝试添加等价端口并提示；没有可用映射时会报告缺失。
- **波形过密或显示不完整**：放大时间窗口后再查看。
- **布局恢复失败**：确认 FST 与保存布局时的工程一致，必要时重新添加信号并保存。
- **添加数量达到上限**：当前最多显示 64 个信号，可先移除暂时不看的信号。
